GoW III Costumes 1.1.0 - visuais para God of War III Remastered
=================================================================

[Português]

Incluído
  * Odisseia Sombria - traje NOVO no menu de trajes (nenhum traje do jogo é substituído):
    pele cinza-carvão, olhos brancos e tatuagem dourada (inspirado no GoW Ragnarok),
    armadura em preto e dourado (inspirado no GoW II) e Lâminas de Atena e do Exílio
    douradas com cabo preto, fogo, faíscas e rastros dourados.
    Bônus (como no GoW II): ataque 2x, dano sofrido 2x, orbes vermelhas 4x.
    Os troféus ficam desabilitados ao usar o traje (como nos trajes do jogo).
    As lâminas douradas aparecem só com a Odisseia Sombria; nos outros trajes as lâminas
    continuam as originais (no SpartanPort isso usa um patch que vem junto com o mod).

Requisitos
  * Sua própria cópia do jogo (CUSA01623). Este pacote NÃO contém arquivos do jogo: o
    instalador lê os arquivos originais do seu jogo e aplica só as partes novas.

SpartanPort (PC)
  1. Extraia este zip em qualquer pasta.
  2. Abra "GoW3 Costumes 1.0.0.exe".
  3. Confira a pasta do jogo (a pasta do SpartanPort, onde está o SpartanPort.exe). Ela é
     preenchida automaticamente quando encontrada; se não, use "Procurar...".
  4. Marque os visuais e clique em "Instalar / atualizar".
  5. Abra o SpartanPort, aba Mods, e confira se "GoW3 Costumes" está ativado.
  6. No jogo: menu Extras > Seleção de traje. A Odisseia Sombria aparece depois dos trajes
     do jogo.

  Remover: abra o instalador e clique em "Remover tudo" (ou desmarque um visual e clique em
  "Instalar / atualizar"), ou só desative o mod na aba Mods do launcher. O jogo original
  nunca é alterado.

  Se o Windows avisar que o programa não é reconhecido (SmartScreen), clique em
  "Mais informações" > "Executar assim mesmo".

PS4 (GoldHEN)
  1. Abra o instalador, marque os visuais e clique em "Gerar arquivos para PS4...".
  2. Selecione a pasta com os arquivos do jogo (a que tem eboot.bin e a pasta EXEC) e onde
     salvar. Será criada a pasta "GoW3 Costumes PS4/EXEC/".
  3. Copie a pasta EXEC para o PS4 usando um redirecionador de arquivos, por exemplo o
     plugin AFR do GoldHEN: /data/GoldHEN/AFR/<ID do jogo>/EXEC/
  4. Lâminas douradas só na Odisseia Sombria: adicione o patch da pasta "GoldHEN" gerada aos
     patches do GoldHEN (/data/GoldHEN/patches/xml/CUSA01623.xml) e ative-o. Feito para a
     versão 01.02 do jogo. Sem o patch, as lâminas ficam as originais em todos os trajes.
  Para remover, apague os arquivos copiados.

Idioma
  O instalador aparece em português quando o Windows está em português. No jogo, o nome e
  a descrição do traje aparecem no idioma do jogo (16 idiomas).


[English]

Included
  * Dark Odyssey - NEW costume in the costume menu (no game costume is replaced): charcoal
    skin, white eyes and golden tattoo (inspired by GoW Ragnarok), black and gold armor
    (inspired by GoW II) and golden Blades of Athena and Exile with black hilts, golden
    fire, sparks and trails.
    Bonus (as in GoW II): 2x attack, 2x damage taken, 4x red orbs.
    Trophies are disabled while using the costume (as with the game's costumes).
    The golden blades appear only with Dark Odyssey; other costumes keep the original
    blades (on SpartanPort this uses a patch that comes with the mod).

Requirements
  * Your own copy of the game (CUSA01623). This package contains NO game files: the
    installer reads the original files from your game and applies only the new parts.

SpartanPort (PC)
  1. Extract this zip anywhere.
  2. Open "GoW3 Costumes 1.0.0.exe".
  3. Check the game folder (the SpartanPort folder, with SpartanPort.exe). It is filled in
     automatically when found; otherwise use "Browse...".
  4. Check the costumes and click "Install / update".
  5. Open SpartanPort, Mods tab, and make sure "GoW3 Costumes" is enabled.
  6. In game: Extras menu > Costume selection. Dark Odyssey comes after the game's costumes.

  Remove: open the installer and click "Remove all" (or uncheck a costume and click
  "Install / update"), or just disable the mod in the launcher's Mods tab. The original
  game is never modified.

  If Windows warns that the app is not recognized (SmartScreen), click "More info" >
  "Run anyway".

PS4 (GoldHEN)
  1. Open the installer, check the costumes and click "Build files for PS4...".
  2. Select the folder with the game files (the one with eboot.bin and the EXEC folder) and
     where to save. A folder "GoW3 Costumes PS4/EXEC/" is created.
  3. Copy the EXEC folder to the PS4 with a file redirector, e.g. the GoldHEN AFR plugin:
     /data/GoldHEN/AFR/<game ID>/EXEC/
  4. Golden blades only with Dark Odyssey: add the patch from the generated "GoldHEN" folder to
     the GoldHEN patches (/data/GoldHEN/patches/xml/CUSA01623.xml) and enable it. Made for game
     version 01.02. Without the patch, all costumes keep the original blades.
  To remove, delete the copied files.

Language
  The installer is shown in Portuguese when Windows is in Portuguese. In game, the
  costume name and description are shown in the game's language (16 languages).
